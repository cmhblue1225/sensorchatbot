# Gravity Toss

중력 조종 공 던지기 게임:

기기를 기울여 공의 궤적을 조절하며 목표물을 맞추는 게임 중력 센서를 활용하여 공의 낙하 속도와 방향을 계산 목표물의 크기와 위치가 점점 작아지고 빨라지는 난이도 증가

## 설치 방법

1. 이 폴더를 `/public/games/` 디렉토리에 복사하세요
2. 폴더명을 `gravity-toss`로 변경하세요
3. 서버를 재시작하거나 게임 재스캔을 실행하세요

## 접속 방법

- 게임 URL: `http://localhost:3000/games/gravity-toss`
- 센서 클라이언트: `http://localhost:3000/sensor.html`
